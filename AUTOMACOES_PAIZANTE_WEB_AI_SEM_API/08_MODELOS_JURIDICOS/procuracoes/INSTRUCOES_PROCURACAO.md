# Instrucoes - Procuracao

## Campos obrigatorios
- Qualificacao completa do outorgante (nome, nacionalidade, estado civil,
  profissao, RG, CPF, endereco).
- Qualificacao do outorgado: Dr. Gustavo Paizante - OAB/MG 180.822.
- Poderes outorgados (ad judicia, ad judicia et extra, poderes
  especiais quando exigidos - ex.: receber valores, transigir, dar
  quitacao).
- Finalidade especifica (processo/causa determinada) quando aplicavel.
- Data e local.
- Espaco para assinatura do outorgante.

## Observacoes
- Use o prompt mestre `07_PROMPTS_MESTRES/01_juridico/` correspondente ou
  o prompt para ChatGPT/Claude com os dados do cliente para gerar a
  minuta.
- Toda procuracao deve identificar claramente o outorgado com a OAB
  correta.
- Assinatura final do documento gerado: Dr. Gustavo Paizante - OAB/MG
  180.822 (como outorgado, quando aplicavel).
