# Instrucoes - Modelos Base Gerais

Esta pasta guarda modelos genericos de peticao/peca que nao se encaixam
nas categorias especificas das demais pastas de `08_MODELOS_JURIDICOS`.

## Estrutura minima recomendada para qualquer peca
1. Endereçamento (juizo/orgao competente).
2. Qualificacao das partes.
3. Exposicao dos fatos.
4. Fundamentacao juridica.
5. Pedidos (principal e subsidiarios, quando aplicavel).
6. Valor da causa (quando exigivel).
7. Local, data e assinatura.

## Assinatura padrao
Toda peca final gerada com apoio desta central deve terminar com:

"Dr. Gustavo Paizante - OAB/MG 180.822"

## Observacao
Use os prompts mestres de `07_PROMPTS_MESTRES/01_juridico/` como ponto de
partida e adapte conforme o tipo especifico de peca.
