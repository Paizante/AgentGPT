# Fluxo Claude via Web

1. No painel, gere o prompt para Claude (botao "gerar prompt Claude").
   Arquivo em `03_FILAS_DE_TRABALHO/03_para_claude/<id_trabalho>.md`.
2. Copie para clipboard.
3. Rode `02_CHROME_WORKSPACE\abrir_claude.ps1` (ou o botao equivalente no
   painel) para abrir https://claude.ai numa nova aba do Chrome.
4. Cole o prompt manualmente, revise e envie voce mesmo.
5. Copie a resposta completa do Claude.
6. Volte ao painel, cole no campo "resposta Claude" e salve. Vai para
   `03_FILAS_DE_TRABALHO/04_retorno_claude/` e `resposta_claude.md`.
7. Marque no checklist que o envio foi manual.
