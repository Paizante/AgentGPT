# Fluxo ChatGPT (Plus ou gratuito) via Web

1. No painel local, gere o prompt para ChatGPT do trabalho atual (botao
   "gerar prompt ChatGPT"). O arquivo fica em
   `03_FILAS_DE_TRABALHO/01_para_chatgpt/<id_trabalho>.md`.
2. Clique em "copiar para clipboard".
3. Rode `02_CHROME_WORKSPACE\abrir_chatgpt.ps1` (ou use o botao do painel
   "abrir ChatGPT no Chrome"). O script so abre https://chatgpt.com numa
   nova aba; o login e a conversa sao manuais.
4. Cole o prompt (Ctrl+V) na caixa de mensagem do ChatGPT, revise o texto
   e só então clique em enviar voce mesmo.
5. Quando a resposta terminar, selecione e copie o texto da resposta do
   ChatGPT.
6. Volte ao painel, cole a resposta no campo "resposta ChatGPT" e salve.
   Ela e gravada em `03_FILAS_DE_TRABALHO/02_retorno_chatgpt/` e no
   arquivo `resposta_chatgpt.md` do trabalho.
7. Marque no painel/checklist que o envio ao ChatGPT foi feito
   manualmente, com data/hora.

ChatGPT e indicado, neste fluxo, para: raciocinio juridico e estrategia de
caso, construcao de tese, redacao final de peca, matriz
fato-prova-direito-pedido, argumentacao persuasiva, esquemas de Visual Law,
mapeamento de riscos e simulacao de possiveis decisoes.
