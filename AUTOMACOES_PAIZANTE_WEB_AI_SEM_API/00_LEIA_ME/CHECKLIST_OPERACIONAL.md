# Checklist Operacional

## Antes de iniciar um trabalho

- [ ] Documentos do caso estao em `04_DOCUMENTOS/entrada/...`?
- [ ] Cliente já tem pasta em `04_DOCUMENTOS/clientes/<cliente>/`?
- [ ] Painel local esta rodando (`http://localhost:8000`)?

## Durante o trabalho

- [ ] Tipo de tarefa selecionado corretamente?
- [ ] Resumo do caso preenchido (sem dados desnecessarios - ver LGPD)?
- [ ] IAs escolhidas fazem sentido para a tarefa (ver fluxos de cada IA)?
- [ ] Prompt revisado antes de colar na IA?
- [ ] Envio feito manualmente, com revisao humana do texto antes de
      enviar?
- [ ] Resposta de cada IA colada e salva no painel?

## Apos coletar as respostas

- [ ] Comparacao gerada e revisada?
- [ ] Consolidacao gerada e revisada?
- [ ] Versao final revisada por humano (advogado responsavel)?
- [ ] Assinatura "Dr. Gustavo Paizante - OAB/MG 180.822" presente na peca
      final?
- [ ] Checklist de protocolo gerado, se aplicavel?
- [ ] Backup do trabalho gerado?

## Antes de protocolar

- [ ] Todos os documentos do pacote de protocolo estao presentes e
      legiveis?
- [ ] Nomes dos arquivos seguem o padrao de
      `04_DOCUMENTOS/saida/pacotes_protocolo`?
- [ ] Revisao final humana concluida e aprovada?
