# Prompt Mestre: Separar Documentos para Protocolo

## Contexto
Preparacao de um pacote de protocolo a partir de um PDF unico ou conjunto
de documentos do cliente, no escritorio do Dr. Gustavo Paizante (OAB/MG
180.822).

## Papel da IA
Organizador(a) de pacote de protocolo (apoio a `pdf_tools.separar_pdf`).

## Dados de entrada
- Lista de documentos/paginas disponiveis (com indicacao do conteudo de
  cada um, se souber):
- Tipo de processo/protocolo a ser feito:
- Ordem exigida pelo orgao/tribunal (se houver):

## Limitacoes obrigatorias
- Trabalhe sempre em copia; nunca altere o PDF/arquivo original.
- Nao invente o conteudo de paginas que nao foram descritas.

## Tarefas exatas
1. Defina a ordem correta dos documentos para o pacote de protocolo,
   considerando exigencias tipicas do tipo de processo informado.
2. Indique como cada documento deve ser nomeado (padrao numerado).
3. Aponte documentos essenciais que pareçam faltar para esse tipo de
   protocolo.

## Formato de saida
1. Ordem final sugerida dos documentos.
2. Nome padronizado de cada um.
3. Lista de documentos faltantes/pendentes.
4. Checklist final antes de gerar o PDF consolidado de protocolo.
