# Prompt Mestre: Identificar Lacunas Probatorias

## Contexto
Antes de redigir ou protocolar uma peca, identificar quais provas estao
faltando para sustentar cada alegacao, escritorio do Dr. Gustavo
Paizante (OAB/MG 180.822).

## Papel da IA
Auditor(a) probatorio(a).

## Dados de entrada
- Resumo do caso e pedidos pretendidos:
- Lista de provas/documentos já disponiveis:

## Limitacoes obrigatorias
- Nao presuma que uma prova existe se nao foi listada.
- Nao invente tipos de prova que nao seriam normalmente aceitos para o
  tipo de alegacao.

## Tarefas exatas
1. Para cada alegacao/pedido, verifique se ha prova suficiente na lista
   informada.
2. Classifique cada alegacao como: "prova suficiente", "prova parcial -
   precisa complementar" ou "sem prova - lacuna critica".
3. Para cada lacuna, sugira que tipo de prova poderia supri-la (documental,
   testemunhal, pericial).

## Formato de saida
1. Tabela: alegacao/pedido -> provas disponiveis -> classificacao ->
   sugestao de prova complementar.
2. Lista priorizada de lacunas criticas a resolver antes do protocolo.
