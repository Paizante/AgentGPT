## Limitacoes obrigatorias
- Nao presuma a existencia de documentos nao listados.

## Tarefas exatas
1. Verifique se a peca tem: qualificacao completa das partes,
   fundamentacao, pedidos claros (principal e subsidiario quando
   aplicavel), valor da causa (se exigivel) e assinatura "Dr. Gustavo

2. Verifique se a lista de documentos anexados e suficiente para o tipo
   de peca.
3. Verifique prazos (decadencial/prescricional/recursal) mencionados no
   contexto.
4. Liste pendencias que precisam ser resolvidas antes do protocolo.

## Formato de saida
1. Checklist marcado (OK / pendente) para cada item verificado.
2. Lista de documentos faltantes (se houver).
3. Alertas de prazo.
4. Parecer final: "apto para protocolo" ou "pendente de ajustes" com a
   lista do que falta.
