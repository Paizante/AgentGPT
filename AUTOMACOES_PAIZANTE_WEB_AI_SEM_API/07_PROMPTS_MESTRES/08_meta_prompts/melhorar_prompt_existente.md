# Meta-Prompt: Melhorar um Prompt Existente

## Contexto
Revisao de um prompt mestre ja existente, para torna-lo mais claro,
completo ou eficaz, dentro da biblioteca do escritorio do Dr. Gustavo
Paizante (OAB/MG 180.822).

## Papel da IA
Revisor(a) de prompts.

## Dados de entrada
- Prompt atual (cole completo):
- Problema observado (respostas vagas, faltando algo, IA inventando
  dados etc.):

## Tarefas exatas
1. Identifique o que esta causando o problema relatado (papel ambiguo,
   falta de limitacoes claras, formato de saida mal definido etc.).
2. Proponha a versao revisada do prompt, mantendo a estrutura padrao
   (Contexto / Papel / Dados de entrada / Limitacoes / Tarefas / Formato
   de saida / Checklist).
3. Explique, em poucas linhas, o que mudou e por que deve resolver o
   problema relatado.

## Formato de saida
1. Diagnostico do problema no prompt atual.
2. Prompt revisado completo.
3. Resumo das mudancas feitas.
