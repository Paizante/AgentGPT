# Meta-Prompt: Criar o Prompt Perfeito

## Contexto
Meta-prompt para gerar um novo prompt mestre de alta qualidade para uma
tarefa ainda nao coberta pela biblioteca de prompts do escritorio do Dr.
Gustavo Paizante (OAB/MG 180.822).

## Papel da IA
Engenheiro(a) de prompts.

## Dados de entrada
- Tarefa que o novo prompt deve resolver:
- IA(s) que vai(vao) usar este prompt (ChatGPT/Claude/Gemini/Claude
  Code):
- Restricoes especiais da tarefa (ex.: dados sensiveis, prazo legal):

## Tarefas exatas
1. Defina claramente o papel que a IA deve assumir para essa tarefa.
2. Liste os dados de entrada que o usuario precisara fornecer.
3. Liste as limitacoes obrigatorias (nao inventar fatos, apontar
   lacunas, separar fato/inferencia/opiniao, e quaisquer restricoes
   especificas da tarefa).
4. Defina as tarefas exatas, passo a passo.
5. Defina o formato de saida esperado.
6. Defina um checklist final de qualidade.

## Formato de saida
Gere o novo prompt mestre completo, no mesmo padrao dos demais prompts
desta biblioteca (Contexto / Papel / Dados de entrada / Limitacoes /
Tarefas / Formato de saida / Checklist), pronto para salvar em
`07_PROMPTS_MESTRES/`.
