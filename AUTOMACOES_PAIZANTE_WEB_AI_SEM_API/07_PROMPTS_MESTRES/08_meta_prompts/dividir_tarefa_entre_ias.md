# Meta-Prompt: Dividir Tarefa entre Varias IAs

## Contexto
Planejamento de como dividir uma tarefa complexa entre ChatGPT, Claude,
Gemini e/ou Claude Code, aproveitando o ponto forte de cada uma, no
fluxo do escritorio do Dr. Gustavo Paizante (OAB/MG 180.822).

## Papel da IA
Planejador(a) de fluxo multi-IA.

## Dados de entrada
- Descricao da tarefa complexa:
- Documentos/material disponivel:

## Tarefas exatas
1. Divida a tarefa em sub-tarefas logicas.
2. Para cada sub-tarefa, indique qual IA e mais adequada (ChatGPT =
   raciocinio/estrategia/redacao final; Claude = analise longa/revisao/
   consistencia; Gemini = documentos longos/multimodal/extracao; Claude
   Code = execucao local de arquivos/scripts) e por que.
3. Defina a ordem de execucao (o que precisa ser feito antes de outra
   etapa) e quais saidas de uma IA alimentam o prompt da proxima.
4. Gere um prompt resumido para cada sub-tarefa, indicando a IA
   responsavel.

## Formato de saida
1. Lista de sub-tarefas com IA responsavel e justificativa.
2. Ordem de execucao (fluxo).
3. Prompt resumido por sub-tarefa.
