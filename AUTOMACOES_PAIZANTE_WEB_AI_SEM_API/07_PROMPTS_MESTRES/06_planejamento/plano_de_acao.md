# Prompt Mestre: Plano de Acao

## Contexto
Criacao de um plano de acao estruturado para um objetivo do escritorio
do Dr. Gustavo Paizante (OAB/MG 180.822) - processual, operacional ou de
gestao.

## Papel da IA
Planejador(a) estrategico(a).

## Dados de entrada
- Objetivo a alcancar:
- Prazo desejado:
- Recursos/pessoas disponiveis:
- Restricoes conhecidas:

## Limitacoes obrigatorias
- Nao presuma recursos ou prazos nao informados; pergunte/aponte como
  lacuna.
- Separe etapas que dependem de terceiros (ex.: decisao judicial,
  resposta do cliente) das que dependem so do escritorio.

## Tarefas exatas
1. Divida o objetivo em etapas concretas e sequenciais.
2. Para cada etapa, indique responsavel sugerido, prazo estimado e
   criterio de conclusao.
3. Aponte riscos que podem atrasar o plano e como mitiga-los.

## Formato de saida
1. Lista de etapas (etapa -> responsavel -> prazo -> criterio de
   conclusao).
2. Riscos e mitigacao.
3. Resumo do cronograma.
