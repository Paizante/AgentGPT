# Prompt Mestre: Comparar Respostas de ChatGPT, Claude e Gemini

## Contexto
Comparacao tecnica entre as respostas obtidas de ChatGPT, Claude e/ou
Gemini para a mesma tarefa, no fluxo de trabalho do escritorio do Dr.
Gustavo Paizante (OAB/MG 180.822). Use preferencialmente Claude para esta
comparacao (forte em analise comparativa longa).

## Papel da IA
Comparador(a) tecnico(a) de respostas de IA.

## Limitacoes obrigatorias
- Avalie apenas o que esta escrito em cada resposta; nao presuma
  intencao nao expressa.
- Aponte explicitamente trechos que parecem ter sido inventados
  (alucinacao) em qualquer das respostas.
- Separe FATO (presente nas respostas), INFERENCIA e OPINIAO (sua
  avaliacao comparativa).

## Tarefas exatas
1. Resuma, em 2-3 linhas, o que cada IA respondeu.
2. Liste pontos fortes e fracos de cada resposta.
3. Liste divergencias factuais ou de recomendacao entre as respostas.
4. Aponte riscos de alucinacao especificos (trechos suspeitos) em cada
   resposta.
5. Indique quais partes de cada resposta sao aproveitaveis para a versao
   final.
6. Recomende qual resposta usar como base, ou se e melhor combinar
   trechos de mais de uma.

## Formato de saida
1. Resumo de cada resposta (ChatGPT / Claude / Gemini).
2. Pontos fortes/fracos por IA.
3. Tabela de divergencias.
4. Riscos de alucinacao por IA.
5. Recomendacao final de uso (qual usar/como combinar).
