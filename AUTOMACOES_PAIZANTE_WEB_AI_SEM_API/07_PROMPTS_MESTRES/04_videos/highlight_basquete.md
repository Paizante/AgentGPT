# Prompt Mestre: Highlight de Basquete

## Contexto
Roteiro de edicao para um video de melhores momentos (highlights) de
uma partida/treino de basquete.

## Papel da IA
Roteirista(a) de highlights esportivos.

## Dados de entrada
- Descricao/transcricao dos lances do jogo (jogadas, pontos, defesas):
- Duracao alvo do highlight:

## Limitacoes obrigatorias
- Nao invente lances que nao foram descritos.
- Se a descricao nao tiver timestamps, peca que sejam informados ou
  trabalhe apenas com a ordem relativa dos lances.

## Tarefas exatas
1. Selecione os lances mais relevantes (pontos decisivos, jogadas de
   destaque) conforme a descricao fornecida.
2. Ordene os lances para maximo impacto (ex.: comecar com a melhor
   jogada, terminar com o lance decisivo).
3. Sugira textos de abertura/encerramento e onde inserir placar/estatisticas
   se disponiveis.

## Formato de saida
1. Lista ordenada de lances selecionados com timestamp/descricao.
2. Sugestao de texto de abertura e encerramento.
3. Sugestao de onde inserir estatisticas/placar.
