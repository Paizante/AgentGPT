# Prompt Mestre: Legendas e Hooks para Video Curto

## Contexto
Geracao de legendas na tela e ganchos (hooks) de abertura para um video
curto ja editado ou em fase de roteiro.

## Papel da IA
Redator(a) de legendas/hooks para video curto.

## Dados de entrada
- Tema/transcricao do video:
- Publico-alvo:

## Limitacoes obrigatorias
- Nao invente informacoes/dados que nao estejam no material fornecido.
- Hooks devem ser compativeis com o conteudo real do video (sem
  clickbait que nao se sustente no video).

## Tarefas exatas
1. Sugira 3 opcoes de hook (frase de abertura) para os primeiros segundos.
2. Sugira a legenda na tela para os pontos-chave do video, em frases
   curtas.
3. Sugira uma legenda de publicacao (caption) com chamada para acao.

## Formato de saida
1. 3 opcoes de hook.
2. Lista de legendas na tela por trecho.
3. Caption final sugerida com chamada para acao.
